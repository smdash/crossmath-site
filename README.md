# crossmath-site

Public pages for **Cross Math** (iOS), served by GitHub Pages.

- Landing: https://smdash.github.io/crossmath-site/
- Support: https://smdash.github.io/crossmath-site/support.html
- Privacy: https://smdash.github.io/crossmath-site/privacy.html

The privacy policy must match the app's real data behaviour (AdMob banner / interstitial / rewarded,
UMP consent, ATT; no analytics, no account, everything else on-device). Update it in the same release
as any change, and keep it consistent with the App Store privacy label.

`app-ads.txt` is NOT here — it lives at the domain root in the `smdash.github.io` repo (account-wide).
